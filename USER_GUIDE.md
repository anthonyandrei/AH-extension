# ArchersHub Enlistment Automator - Easy User Guide

> [!NOTE]
> The **Run Now** and **Schedule** (Save Schedule / Clear Schedule) features described later in this guide have been temporarily removed while the extension is being rebuilt. The popup currently only lets you maintain a subject list (add/remove subjects).

This guide is written for non-technical users.
You do not need coding knowledge to use this.

## What This App Does

This Chrome add-on helps you do enlistment faster on ArchersHub.

You can:
- add your subjects and sections,
- run enlistment now, or
- set a date and time so it runs later.

Important: it uses your current ArchersHub login. It does not ask for your password.

## Before You Begin

Prepare these first:
- Google Chrome installed
- your ArchersHub account
- your subject code and section (example: GEUSELF and Y01)

## Install It (One-Time Setup)

1. Open Chrome.
2. Type this in the address bar: chrome://extensions/
3. Turn on **Developer mode** (top-right switch).
4. Click **Load unpacked**.
5. Select the folder named **extension**.
6. Check that you can see **ArchersHub Enlistment Automator** in your extensions.

If it appears in the list, setup is done.

## First Use (Quick Steps)

1. Open ArchersHub and log in.
2. Go to the enlistment page.
3. Click the extension icon in Chrome.
4. Add your subjects and sections.
5. Choose:
   - **Run Immediately** if you want to run now, or
   - **Schedule for Date & Time** if you want it to run later.

## How to Add Subjects

1. In the extension popup, enter:
   - **Subject Code**
   - **Section**
2. Click **Add Subject**.
3. Repeat for your other subjects.
4. To remove one, click **Delete** beside it.

Tips:
- Use the exact subject code and section from ArchersHub.
- You cannot add the same subject code twice.

## Option A: Run Now

Use this if you want immediate execution.

1. Make sure ArchersHub enlistment page is open.
2. Make sure you are logged in.
3. Open the extension popup.
4. Click **Run Now**.
5. Wait and watch the **Execution Log**.

## Option B: Schedule for Later

Use this if you want automatic execution at a specific time.

1. Select **Schedule for Date & Time**.
2. Pick a future date and time.
3. Click **Save Schedule**.

Important for scheduled runs:
- Keep Chrome open (or running in the background).
- Keep your ArchersHub enlistment tab available and logged in.

To cancel a schedule, click **Clear Schedule**.

## How to Read the Status

In the popup, you will see:
- **Status**: Not Scheduled, Scheduled, Running, or Error
- **Execution Log**: step-by-step messages with time

## If Something Goes Wrong

### Message: Enlistment page tab not found
Fix:
- Open ArchersHub enlistment page in a tab.
- Try again.

### Message: Unable to connect to enlistment page
Fix:
- Refresh the enlistment tab.
- Open the extension popup again and retry.

### Subject was not selected
Fix:
- Check spelling of subject code and section.
- Make sure that subject/section is available in ArchersHub.

### Scheduled run did not start
Fix:
- Check that scheduled date/time is in the future.
- Keep Chrome running.
- Keep ArchersHub tab logged in.

### Login/session issue
Fix:
- Log in to ArchersHub again, then run again.

## Privacy

The app saves only these on your computer:
- subject list
- schedule settings
- execution logs

It does not store your password.
